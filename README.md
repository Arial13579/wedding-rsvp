## צעד חובה אחד: עדכון כללי האבטחה ב־Firebase

1. נכנסים ל־[Firebase Console](https://console.firebase.google.com/project/wedding-rsvp-e2e0f/firestore/rules) ← Firestore Database ← **Rules**.
2. מוחקים את מה שיש ומדביקים את כל התוכן של הקובץ [`firestore.rules`](firestore.rules).
3. לוחצים **Publish**.

> **שימו לב:** הפרויקט `wedding-rsvp-e2e0f` משמש גם את אתר הצעות המחיר של Snap Box. הקובץ `firestore.rules` כולל את הכללים של שני האתרים, ותמיד צריך להדביק אותו במלואו. הדבקה של כללים של אתר אחד בלבד תחסום את האתר השני.

עד שזה נעשה, האתר עובד, אבל קישורי השותפים לא יעבדו, וכל חשבון Google שמתחבר יכול לראות את רשימת המוזמנים. הכללים החדשים סוגרים את זה: רק את/ה ושותפים שהוזמנו.

## איך זה עובד

1. **סבב ראשון** (אתה, ידנית): שליחה ← סבב ראשון. כל אורח מקבל הודעה אישית עם קישור.
2. **תזכורות חכמות**: מי שלא ענה או סימן "מתלבט" נכנס לתזכורות אחרי שבוע, עד 3 פעמים (ניתן לשינוי בהגדרות). מי שסימן **לא מגיע** לא יקבל יותר הודעות. התזכורות המוכנות מופיעות בסיכום ועם מספר אדום על לשונית "שליחה", ושולחים בלחיצה לכל אורח.
3. **יומיים לפני החתונה** נפתחת תזכורת למי שאישר, עם קישור לניווט.
4. **אחרי החתונה** נפתחת הודעת תודה, וסימון מי הגיע ורישום מתנות.

עוד: הושבה בשולחנות, ספירה לקייטרינג (כולל מנות מיוחדות שהאורחים בוחרים), ברכות מהאורחים, ייצוא לאקסל, ו"התחלת אירוע חדש" בהגדרות שמוחקת הכול.

## באייפון

- פותחים את כתובת הניהול ב־Safari ← שיתוף ← **הוספה למסך הבית**.
- בחירת אנשי קשר ישירות מהטלפון: הגדרות ← אפליקציות ← Safari ← מתקדם ← Feature Flags ← **Contact Picker API**. בלי זה אפשר לייבא קובץ של כל אנשי הקשר ולבחור מתוכו.
- באנדרואיד (Chrome) הבחירה מאנשי הקשר עובדת בלי הגדרות.
