    1. נכנסים ל־console.firebase.google.com ומתחברים עם arielkahalani1@gmail.com.

  3. הפעלת התחברות עם Google

    1. בתפריט הצד: Build ← Authentication ← Get started.
    2. בטאב Sign-in method — לוחצים על Google ברשימה.
    3. מפעילים את המתג Enable.
    4. בשדה "Support email" בוחרים arielkahalani1@gmail.com ← Save.

  4. רישום אפליקציית ווב + העתקת המפתחות

    1. למעלה מימין: גלגל השיניים ⚙ ← Project settings.
    2. גוללים למטה עד הקטע Your apps.
    3. לוחצים על אייקון הווב </>.

    המפתחות האלה אינם סוד. מפתח Firebase של אתר הוא מזהה פרויקט, לא סיסמה — מותר לגמרי להעלות אותו ל-GitHub. מי ששומר על המידע הם כללי האבטחה (שלב 5) + התחברות Google.

  5. הדבקת כללי האבטחה

    1. תפריט הצד: Build ← Firestore Database ← טאב Rules.
    2. מוחקים את כל מה שכתוב שם.
    3. מדביקים במקום את הקוד הבא (כפתור "העתק"):
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    match /guests/{id} {
      allow get: if true;
      allow list, create, delete: if request.auth != null;
      allow update: if request.auth != null
        || (
             request.resource.data.name  == resource.data.name &&
             request.resource.data.phone == resource.data.phone &&
             request.resource.data.diff(resource.data).affectedKeys()
               .hasOnly(['status','adults','children','total','updatedAt','remindOn'])
           );
    }

    match /meta/{doc} {
      allow read:  if true;
      allow write: if request.auth != null;
    }
  }
}
    1. לוחצים Publish.
    ✓ אמור לקרות: הודעה "Rules published" והתאריך מתעדכן.
